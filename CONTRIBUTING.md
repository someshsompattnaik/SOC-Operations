# Contributing to SOC War Room Defense Matrix

First off, thank you for taking the time to contribute to the **SOC War Room Presentation Suite**! 🚀

This project is tailored to empower engineering students and budding security analysts with realistic, interactive defensive cybersecurity skills.

---

## 🛠️ How to Contribute

### 1. Proposing New Detection Rules & Scenarios
- Have an idea for a new Sigma detection rule, Suricata signature, or EDR telemetry scenario?
- Open an Issue describing the attack vector (MITRE ATT&CK ID) and the corresponding defensive triage steps.

### 2. Reporting Bugs or Display Issues
- If you notice visual formatting issues, audio synthesizer glitches, or fullscreen behavior anomalies in specific browsers, please open an Issue with:
  - Browser name & version (e.g., Chrome 124, Firefox 125, Edge)
  - Display resolution
  - Steps to reproduce

### 3. Submitting Pull Requests
1. Fork the repository on GitHub.
2. Create your feature branch (`git checkout -b feature/sigma-hunt-scenario`).
3. Commit your enhancements (`git commit -m "feat: Add atomic Sigma hunt query for LSASS dump"`).
4. Push to the branch (`git push origin feature/sigma-hunt-scenario`).
5. Open a Pull Request against the `main` branch.

---

## 🎨 Code Style Guidelines

- **Zero External Dependencies**: Keep everything native HTML5, CSS3, and vanilla JavaScript (no npm/bundler required) to preserve instant portability.
- **Sci-Fi Theme Consistency**: Preserve the deep space palette (`#030712`, `#060d1e`), neon cyan (`#00f0ff`), electric blue (`#0070f3`), and monospace typography.
- **Terminal Authenticity**: Ensure interactive terminals adhere to zero-gap monospace styling with clear input/output differentiation.
