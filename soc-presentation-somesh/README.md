## 🌌 Overview

The **SOC War Room Defense Matrix** is an interactive, cinematic web-based slide deck and live combat simulation environment built to introduce university students to real-world defensive cybersecurity operations.

Instead of static, bullet-heavy slides, this presentation transforms any classroom or auditorium display into an enterprise **SOC War Room Tactical Cockpit**. It integrates live client-side attack detonations, defensive mitigation playbooks, deep tool dossiers, and a high-stakes ransomware crisis investigation (DFIR) — completely running in vanilla HTML5, CSS3, and JavaScript with **zero external dependencies**.

---

## ⚡ Key Sci-Fi Command Center Features

- **🌐 Holographic Laser Node Network**: Dynamic HTML5 canvas rendering an interactive constellation of telemetry nodes connected by vector beams that react magnetically to the presenter's mouse movements.
- **⛶ 100% Continuous Locked Fullscreen**: Engineered as a Single Page Application (SPA). Switching between slides or using keyboard arrows maintains true fullscreen without ever dropping out to the browser window.
- **🔊 Web Audio API Tactical Sound Synthesizer**: Native harmonic sound effects for slide switching, attack alarms, containment confirmations, and audio mute toggle (`S` key).
- **📟 High-Density Zero-Gap Monospace Terminals**: Authentic Unix/PowerShell terminals with realistic prompt styles, animated character streaming, and blinking prompt cursors.
- **🎮 Interactive Dual Combat Controls**: Every module is equipped with:
  - `[ ⚡ Simulate Attack Vector ]` : Executes real-world offensive techniques (SQLi, Kerberoasting, LSASS injection, Ransomware spread).
  - `[ 🛡️ Execute Defense / Resolve ]` : Triggers automated containment, virtual patching, RAM forensics, and threat neutralization.
  - `[ ⌫ Clear Terminal ]` : Instantly wipes terminal logs so you can re-run demonstrations dynamically for students.
- **🗺️ HUD Matrix Module Overview (`M` Key)**: A holographic modal grid providing one-click teleportation to any of the 14 curriculum modules.

## 🚀 Running Locally

No build tools, Node.js, or complex dependencies are needed!

### Method 1: Direct File Opening
Double-click [`index.html`](index.html) to open directly in Google Chrome, Microsoft Edge, Brave, or Mozilla Firefox.

### Method 2: Python Local HTTP Server
```bash
# In the repository root directory:
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`

### Method 3: VS Code Live Server
Right-click `index.html` in VS Code and select **"Open with Live Server"**.

## 🌐 Deployment to GitHub Pages

Deploying this presentation deck live on the web is completely free and takes under 60 seconds:

### Option A: Automated GitHub Actions (Recommended)
This repository includes a pre-configured `.github/workflows/deploy.yml` workflow:
1. Push your repository to GitHub.
2. In your GitHub repository, navigate to **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
4. Every push to `main` will automatically build and publish your presentation live!

### Option B: Direct Branch Deployment
1. Go to **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Source**, select **Deploy from a branch**.
3. Set branch to `main` (or `master`) and folder to `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
